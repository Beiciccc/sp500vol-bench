# RTX 3090 to RTX 4090 ETA for C1/C2/C3/D1/D2

Assumptions: dataset `full`, seed 2026, 3 epochs, train.py effective-trading-day split, checkpoint disabled for fresh runs, and 24GB production batch sizes from `rtx3090_probe_24g_summary.csv`. C4 Longformer is excluded because this ETA is for C1/C2/C3/D1/D2. C1_bert_s2 uses C2_finbert_s2 as a proxy because it was not in the measured 3090 probe grid but shares the same BERT-base S2 chunk pipeline.

Prediction time is estimated as 0.35x one train step per predict batch. GPU train ETA is exact from measured 3090 step time and exact row counts; full wall-clock can move with text I/O, tokenizer CPU speed, and first-time model downloads.
